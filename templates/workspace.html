Variable templates

Use {{ "{{ var.NAME }}" }}, {{ "{{ env.NAME }}" }}, and {{ "{{ run.NAME }}" }} in any text field (URL, body, script, args…). Sensitive workspace variables are always masked as ***.

var.* — Workspace variables

  • {{ "{{ var.workspace_name }}" }}
  • {{ "{{ var.workspace_id }}" }}
  • {{ "{{ var.MY_VAR }}" }} (workspace var)

env.* — OS environment

  • {{ "{{ env.HOME }}" }}
  • {{ "{{ env.PATH }}" }}
  • {{ "{{ env.ANY_VAR }}" }}

run.* — Execution context

  • {{ "{{ run.status }}" }} completed / failed
  • {{ "{{ run.command }}" }} plan / apply
  • {{ "{{ run.id }}" }}, {{ "{{ run.duration }}" }}
  • {{ "{{ run.terraform_version }}" }}

Scripts also receive all run.* values as TGM_* environment variables (e.g. TGM_STATUS, TGM_COMMAND).
