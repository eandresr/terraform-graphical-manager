Portal Security

{% if config.lock_password_hash %} Protected {% else %} Unlocked {% endif %}

Set a password to restrict access to the portal. Browser sessions are protected with a login page. Direct API calls require an Authorization: Bearer <token> header. The password is stored as a PBKDF2 hash in tfg.conf.

Leave blank to keep the current password unchanged. For sensitive variable encryption, use a strong passphrase — 8 random words or a 100-bit random string recommended.

Run History Retention

Auto-cleanup on

Controls how long execution logs, plan files, and metadata are kept per workspace. Files are always stored in the active TERRAFORM_GRAPHICAL_BACKEND (configured via environment variables — see the backend panel below). Cleanup runs automatically when a new execution finishes for that workspace.

By run count

Older runs (logs, plan files, metadata) are deleted to stay within this limit.

By age

Based on the run's start timestamp. At least one run is always retained even if it is older.

By size

Oldest runs are removed until the total stored size per workspace is within the limit.
